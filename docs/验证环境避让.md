# 验证设备唯一指定（用户 2026-10-20 确认，最高优先级）

**我只能操作 `127.0.0.1:16416`（MuMu Player 12 index 1「MuMu安卓设备-1」，Android 12 / API 32 / 720×1280 / SM-S7110）。**

- 绝对禁止触碰 `emulator-5554` 与 `127.0.0.1:7555`（index 0 实例，另有会话在用）。
- 所有 adb 命令必须显式 `-s 127.0.0.1:16416`，adb 路径 `C:\Program Files\Netease\MuMu Player 12\shell\adb.exe`。
- 该设备 offline 时：先 `adb disconnect 127.0.0.1:16416` → `adb connect 127.0.0.1:16416` 重连；仍不行则停止并报告，不得改连其他设备。
- 装机后固定三步授权：`settings put secure enabled_accessibility_services com.auto.fairy/com.auto.fairy.AutoFairyAccessibilityService`、`settings put secure accessibility_enabled 1`、`cmd appops set com.auto.fairy SYSTEM_ALERT_WINDOW allow`。
- 遇设备被其他进程/人抢占（界面不属于 com.auto.fairy 且持续异常）→ 停手报告。
