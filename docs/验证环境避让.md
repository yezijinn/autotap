# 验证设备唯一指定

**验证只在 OPPO Reno11 Pro（PJJ110）真机上执行。**

- 动手前先跑 `adb devices -l`，只认 `model:PJJ110` 那一行；同机可能还连着别的真机与模拟器，未确认的序列号一律不碰。
- 命令一律显式带目标：`adb -s <序列号> <命令>`。序列号以实时输出为准，不在文档里固定记录。
- 分辨率、density、系统版本现场读取：`adb shell wm size`、`adb shell wm density`、`adb shell getprop ro.build.version.release`；坐标类改动按读到的值复测，其他分辨率仅作参考。
- 设备 offline 时：`adb disconnect <序列号>` → `adb connect <序列号>` 重连；仍不通就停止并报告，不得改连其他设备。
- 装机后三步授权（`<applicationId>` 为装机标识，`<namespace>` 为源码包名）：
  - `settings put secure enabled_accessibility_services <applicationId>/<namespace>.AutoFairyAccessibilityService`
  - `settings put secure accessibility_enabled 1`
  - `cmd appops set <applicationId> SYSTEM_ALERT_WINDOW allow`
- 目标设备界面不属于本应用且持续异常（被其他进程或他人占用）→ 停手报告。
